《版醒》GitHub Pages 网站根目录

上传后，仓库根目录应直接看到：
- index.html
- app.js
- styles.css
- assets/
- tracking/targets.mind
- .nojekyll

不要把这些文件再套一层 webar 文件夹，否则页面地址会多一级路径。

GitHub Pages 设置：
Settings → Pages
Build and deployment → Source: Deploy from a branch
Branch: main
Folder: /(root)
Save

发布后网址通常为：
https://<GitHub用户名>.github.io/<仓库名>/

获得真实网址后，用手机访问并测试四张识别图。
